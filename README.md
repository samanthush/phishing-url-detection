# An Explainable Graph-Based Phishing URL Detection Framework

COM713 Advanced Data Structures and Algorithms – Task 2

## Overview

This project implements an explainable graph-based phishing URL
detection framework. The system combines URL-based machine
learning classification with heterogeneous graph construction,
Breadth-First Search (BFS), evidence extraction, evidence ranking,
and human-readable explanation generation.

## Main Components

- PhiUSIIL phishing URL dataset
- Random Forest classification
- Heterogeneous graph construction
- Breadth-First Search
- Evidence extraction
- Evidence ranking
- Human-readable explanation generation
- Object-oriented implementation

## Dataset

A 10,000-record sample of the PhiUSIIL Phishing URL Dataset
was used for this implementation.

Source:
UCI Machine Learning Repository
